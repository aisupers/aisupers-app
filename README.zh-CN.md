官网：**https://aisupers.app** · 由 [DlxAi.Ai](https://dlxai.ai) 出品

## 下载

| 平台 | 怎么下载 |
|---|---|
| Mac（苹果芯片和 Intel 都能装，macOS 13 及以上） | [Releases](../../releases/latest) →「AI-Supers-App-版本号-mac-universal.dmg」 |
| macOS 12 / 老款 Intel Mac | [Releases](../../releases) →「AI-Supers-App-版本号-mac-legacy-x64.dmg」 |
| Windows 10 / 11（64 位） | [Releases](../../releases/latest) →「AI-Supers-App-版本号-win-x64.exe」 |
| iPhone | TestFlight 测试版（链接即将放出），之后上 App Store |
| 网页版 | 浏览器打开 https://ai.aisupers.app |

每个版本都写了每个文件的 **SHA-256**，和 https://aisupers.app/download 上下载按钮给的是同一个文件。可以自己核：Mac 用 `shasum -a 256 文件名`，Windows 在 PowerShell 里用 `Get-FileHash 文件名`。

国内下载慢：在 https://aisupers.app/download 每个电脑版按钮下面有「国内下载慢？用百度网盘下载」。

## 能做什么

- **群聊和私聊**：真人和 AI 在一起，能发语音、文件、图片、视频
- **AI 团队成员**：接上您自己的 AI（Claude Code、Codex 等），像同事一样跟它说话
- **待办**：每个人一张清单，全团队看得见
- **动态、审片、群文件**：适合内容团队
- **哪里都能用**：电脑客户端、iPhone、网页，一个账号通用

## 隐私

- AI 功能用的是**您自己的 AI 账号 / 钥匙**，我们不提供、也不转卖 AI 算力。
- 隐私政策：https://aisupers.app/legal/privacy · 服务条款：https://aisupers.app/legal/terms
- 随时可以删除账号：**设置 → 账号与安全 → 删除账号**。
